# Sanjeevani (sanjeevani_szv) 🎓🌿

> **Student Innovation – Smart Education**  
> Peer-to-Peer Smart Learning Platform connecting school students (Classes 5–12, JEE, NEET) with top verified college mentors from IITs, NITs, BITS Pilani, and AIIMS.

---

## 🌟 Key Features

- **1:1 Live Mentorship**: Real-time sessions with exam rankers from top engineering and medical institutes.
- **Structured Cohort Batches**: Small-group live interactive classes with capped seats and real-time enrollment progress.
- **Interactive Live Classroom**: Built-in interactive whiteboard with pencil/highlighter tools, color palettes, clearing, video simulation, raised hand status, and student-mentor chat.
- **Dual Dashboard**: Seamless switching between Student Mode (wallet tokens, booked sessions, live joins) and Mentor Mode (incoming requests, earning stats, session schedules).
- **Google Meet Integration**: Automated Google Meet room creation and instant 1-click joining for scheduled sessions.
- **24/7 Sanjeevani AI Tutor**: Instant doubt resolution assistant for JEE, NEET, and school curriculum questions.
- **College Mentor Onboarding Wizard**: Multi-step verification form for college students to verify college IDs and entrance exam ranks.
- **Theme Support**: Seamless dark mode and light mode switching with high-contrast, distraction-free readability.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/sanjeevani.git
cd sanjeevani
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000`.

### 4. Build for Production
```bash
npm run build
```
The compiled static assets will be in the `dist/` directory ready for deployment.

---

## 🚢 Deployment to Vercel / Netlify

### Deploy on Vercel
1. Push your code to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your `sanjeevani` GitHub repository.
4. Framework Preset: **Vite**
5. Build Command: `npm run build`
6. Output Directory: `dist`
7. Click **Deploy**.
